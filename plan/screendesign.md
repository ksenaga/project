画面設計
画面構成
・ログイン画面(/login)
・プロジェクト一覧(/projects)
・タスク一覧(/projects/{id}/tasks)
・タスク詳細(タスク一覧の上に開くモーダル)
・画面名の管理(タスク一覧の上に開くモーダル)
・ユーザー一覧(/users)
・ユーザー詳細(ユーザー一覧の上に開くモーダル)
※プロジェクト詳細は独立した画面を持たない。プロジェクトの情報はプロジェクト一覧のカードとタスク一覧のヘッダーに表示し、編集はプロジェクト一覧の編集モーダルで行う

共通
・ログイン後の画面は上部にヘッダーを表示する(アプリ名/「プロジェクト」「ユーザー」の切り替え/ログインユーザー名/ログアウト)
・ログインしていない状態でログイン後の画面を開くと、ログイン画面に移動する
・ログイン済みでログイン画面を開くと、プロジェクト一覧に移動する
・操作が成功すると画面下部にメッセージを表示する

画面操作
ログイン画面
 └─ ユーザー名・パスワードを入力して「ログイン」

プロジェクト一覧
 ├─ プロジェクトを縦一列のカードで表示(プロジェクト名/プロジェクト詳細/期限/メンバー)
 ├─ 期限切れ・期限が7日以内のときは期限の横にラベルを表示(期限切れ/今日まで/あと○日)
 ├─ メンバーはアイコンで表示し、横幅に入りきらない人数は「+N」で表示
 ├─「＋」→ 作成モーダル(プロジェクト名/プロジェクト詳細/期限/メンバー)
 ├─「編集」アイコン → 編集モーダル
 ├─「削除」アイコン → 削除確認モーダル
 └─ カードをクリック → タスク一覧

タスク一覧
 ├─ ヘッダーにプロジェクト名/期限/タスク件数/メンバーを表示
 ├─ 絞り込み(文字/担当者/画面名。すべての条件に当てはまるタスクを表示)
 │    ├─ 文字:タイトル・説明・修正内容・修正理由・メモに含まれるもの(入力が止まってから検索)
 │    ├─ 担当者:プロジェクトメンバーから選ぶ(すべて)
 │    ├─ 画面名:登録された画面名から選ぶ(すべて)
 │    ├─ 期限:「から」「まで」の日付で範囲を指定(片方だけでもよい)
 │    ├─ 期限の色:赤(7日以内)/黄色(8〜14日)/黄緑(15日以上)から選ぶ(すべて)。完了・対応中止は含まない
 │    ├─ 絞り込み中は一致した件数を表示。「条件をクリア」で解除
 │    └─ 一致するタスクがないときは「条件に一致するタスクはありません」
 ├─ ヘッダーの「画面名の管理」→ 画面名の管理モーダル
 ├─ 未対応・対応中・レビュー中・完了・対応中止の列でタスクのカードを表示(期限が近い順)
 ├─ カードには画面名/タイトル/期限/担当者を表示
 ├─ 期限は今日からの日数で色を付ける:7日以内(期限切れを含む)は赤、8〜14日は黄色、15日以上は黄緑。完了・対応中止は色なし
 ├─ カードを別の列にドラッグ&ドロップ → ステータスを変更
 ├─ 未対応・対応中の列の「＋」→ 作成モーダル(押した列のステータスが初期値)
 ├─ カードをクリック → タスク詳細
 └─「←」→ プロジェクト一覧

画面名の管理(モーダル)
 ├─ プロジェクトに登録された画面名を名前順で表示(使っているタスク数付き)
 ├─ 画面名を入力して「追加」
 ├─「編集」アイコン → その場で名前を変更して「保存」
 └─「削除」アイコン → 削除(タスクで使われている画面名は削除できない)
※タスクの作成・編集では、画面名をここで登録したものからプルダウンで選ぶ(必須)。新しい画面の場合は先にここで登録する

タスク詳細(モーダル)
 ├─ ステータス/タイトル/担当者/期限/画面名/説明/修正内容/修正理由/Git URL/メモを表示
 ├─「編集」→ 編集モーダル
 ├─「コピー」→ 作成モーダル(内容をコピー。Git URL・期限・修正内容・修正理由・メモは空)
 └─「削除」→ 削除確認モーダル

ユーザー一覧
 ├─ ユーザーを縦一列のカードで表示(id順。名前/権限/参画プロジェクト数。idは表示しない)
 ├─「＋」→ 登録モーダル(ユーザー名/パスワード/権限)
 ├─「編集」アイコン → 編集モーダル(パスワードは変更する場合のみ入力)
 ├─「削除」アイコン → 削除確認モーダル
 └─ カードをクリック → ユーザー詳細

ユーザー詳細(モーダル)
 ├─ 名前/権限/参画しているプロジェクト名(期限が近い順)を表示
 ├─ プロジェクト名をクリック → タスク一覧(管理者か本人が見ているときのみ)
 └─「編集」→ 編集モーダル

アクセス詳細
管理者
・ログイン画面
・プロジェクト一覧→作成・編集・削除が可能(プロジェクト名や詳細、メンバーなど)
・タスク一覧→全プロジェクトのタスク一覧に移動できる。全てのステータスに移動できる
・タスク詳細→編集・コピー・削除が可能
・ユーザー一覧→登録・編集・削除が可能(自分自身の削除と、自分の権限の変更はできない)

リーダー
・ログイン画面
・プロジェクト一覧→閲覧のみ。メンバーになっているプロジェクトのみタスク一覧に移動できる
・タスク一覧→作成が可能。全てのステータスに移動できる
・タスク詳細→編集・コピー・削除が可能
・ユーザー一覧→全ユーザーを閲覧できる。自分のアカウント(名前・パスワード)のみ変更可能

一般ユーザ
・ログイン画面
・プロジェクト一覧→閲覧のみ。メンバーになっているプロジェクトのみタスク一覧に移動できる
・タスク一覧→作成が可能。自分が担当するタスクのみ未対応/対応中/レビュー中に移動できる
・タスク詳細→自分が担当するタスクのみ編集が可能(ステータス(未対応/対応中/レビュー中まで)/修正内容/修正理由/git url/メモ)。コピーが可能。削除は不可
・ユーザー一覧→全ユーザーを閲覧できる。自分のアカウント(名前・パスワード)のみ変更可能
