画面設計
画面構成
・ログイン画面(/login)
・タスク一覧(/my-tasks。自分が担当しているタスク。プロジェクトごとのタスク一覧とは別の画面)
・プロジェクト一覧(/projects)
・タスク一覧(/projects/{id}/tasks)
・タスク詳細(タスク一覧の上に開くモーダル)
・画面名の管理(タスク一覧の上に開くモーダル)
・ユーザー一覧(/users)
・ユーザー詳細(ユーザー一覧の上に開くモーダル)
※プロジェクト詳細は独立した画面を持たない。プロジェクトの情報はプロジェクト一覧のカードとタスク一覧のヘッダーに表示し、編集はプロジェクト一覧の編集モーダルで行う

共通
・ログイン後の画面は上部にヘッダーを表示する(アプリ名/「タスク一覧」「プロジェクト」「ユーザー」の切り替え/ログインユーザーのアイコン・名前/通知のベル/ログアウト)
・ユーザーのアイコンは、画像を設定していれば画像、なければ名前の頭文字(ユーザーごとの色)で表示する
・通知のベル:未読の件数をバッジで表示。クリックで通知の一覧(新しい順に30件。未読は色付き)を開き、通知を押すと既読にしてそのタスクの詳細(プロジェクトの通知はタスク一覧)を開く。「すべて既読にする」あり
・新しい通知は30秒ごとと、タブに戻ってきたときに確認し、届いたらヘッダーの下に「新しい通知があります」と表示する(「見る」で一覧を開く)
・タスク一覧は URL に ?task=ID を付けて開くと、そのタスクの詳細を開いた状態になる
・/tasks/{ID} を開くと、そのタスクのプロジェクトのタスク一覧へ移動して詳細を開く(コメントの「#ID」やタスクのリンクで使う。見られないタスクはエラーを表示)
・ログインしていない状態でログイン後の画面を開くと、ログイン画面に移動する
・ログイン済みでログイン画面を開くと、プロジェクト一覧に移動する
・操作が成功すると画面下部にメッセージを表示する

画面操作
ログイン画面
 └─ ユーザー名・パスワードを入力して「ログイン」

タスク一覧(ヘッダーの「タスク一覧」。/my-tasks)
 ├─ 自分が担当しているタスクを、プロジェクトをまたいで1つの表に表示(最初は未完了のみ・期限が近い順)
 │    └─ 列:タスク名(コメントがあれば右端にアイコン)/プロジェクト/ステータス(ボードのリストと同じ名前・色)/期限(期限の色)/タグ/画面名
 ├─ 上に期限の色ごとの件数(7日以内/8〜14日/15日以上)。押すとその色だけに絞り込む(もう一度押すと解除)
 ├─ 絞り込み:タスク名の文字/プロジェクト/「完了・対応中止も表示」。「条件をクリア」で解除
 ├─ タスク名・プロジェクト・期限の見出しで並び替え
 └─ 行をクリック → そのプロジェクトのタスク一覧でタスク詳細を開く(タスク名は Ctrl + クリックで別タブでも開ける)

プロジェクト一覧
 ├─ プロジェクトを縦一列のカードで表示(プロジェクト名/フェーズ/進捗度/期限/メンバー)。プロジェクト詳細は表示しない
 ├─ フェーズ:管理者と、参画しているリーダーはプルダウンでその場で変更できる。それ以外は表示のみ
 ├─ 進捗度:完了のタスク数 ÷ (未対応・対応中・レビュー中・完了のタスク数)。バーと「○%(完了 N / M 件)」で表示。タスクがないときは「タスクなし」
 ├─ 期限切れ・期限が7日以内のときは期限の横にラベルを表示(期限切れ/今日まで/あと○日)
 ├─ メンバーはアイコンで表示し、横幅に入りきらない人数は「+N」で表示
 ├─「＋」→ 作成モーダル(プロジェクト名/プロジェクト詳細/期限/メンバー)
 ├─「編集」アイコン → 編集モーダル(管理者と、担当しているリーダー)
 ├─「削除」アイコン → 削除確認モーダル(管理者のみ)
 ├─「詳細を見る」アイコン → 詳細モーダル(編集できない人。編集モーダルと同じ内容を閲覧のみで表示。「閉じる」のみ)
 │    └─ 詳細・編集モーダルでは、メンバーの下に「変更履歴」のアコーディオン(閉じた状態。開くと読み込む)。
 │       新しい順に、操作した人のアイコン・名前・経過時間と、変更した内容(作成/名前・詳細・期限/メンバーの追加・外す/フェーズ)を表示。全ロールが見られる
 └─ カードをクリック → タスク一覧

タスク一覧
 ├─ ヘッダーにプロジェクト名/期限/タスク件数/メンバーを表示
 ├─ 絞り込み(文字/担当者/タグ/画面名。すべての条件に当てはまるタスクを表示)
 │    ├─ 文字:タイトル・説明・修正内容・修正理由・メモに含まれるもの(入力が止まってから検索)
 │    ├─ 担当者:プロジェクトメンバーから選ぶ(すべて)
 │    ├─ タグ:8つのタグから選ぶ(すべて)。選んだタグが付いているタスクを表示
 │    ├─ 画面名:登録された画面名から選ぶ(すべて)
 │    ├─ 期限:「から」「まで」の日付で範囲を指定(片方だけでもよい)
 │    ├─ 期限の色:赤(7日以内)/黄色(8〜14日)/緑(15日以上)から選ぶ(すべて)。完了・対応中止は含まない
 │    ├─ 絞り込み中は一致した件数を表示。「条件をクリア」で解除
 │    └─ 一致するタスクがないときは「条件に一致するタスクはありません」
 ├─ ヘッダーの「画面名の管理」→ 画面名の管理モーダル
 ├─ ヘッダーの「ボード / リスト」で表示を切り替える(選んだ表示はブラウザに保存し、次に開いたときもその表示)
 │    └─ リスト表示:1行に1タスクの表。タスク名は常に一番左に表示し、横にスクロールしても残る。
 │         「表示する項目」で列を選べる(ステータス/期限/担当者/タグ/画面名/説明/修正内容/修正理由/Git URL/メモ。最初はステータス〜画面名。選んだ列はブラウザに保存。「最初の表示に戻す」あり)。
 │         長い文章は2行まで(マウスを合わせると全文)。Git URL はリンク(押すと別タブで開き、詳細は開かない)。
 │         見出しをクリックでその列で並び替え(もう一度押すと逆順)。ステータスはボードの列の並び順。最初は期限が近い順。
 │         行をクリックでタスク詳細。絞り込みはリスト表示にも効く。ドラッグ&ドロップはボード表示のみ
 ├─ 未対応・対応中・レビュー中・完了・対応中止と、追加したリストの列でタスクのカードを表示(列は設定した並び順、カードは期限が近い順)
 ├─ リストの背景は明るめの色(既存の5つ:未対応=グレー、対応中=青、レビュー中=黄色、完了=緑、対応中止=赤)
 ├─ 一番右の「リストを追加」→ リスト名を入力し、12色から背景色を選んで「追加」(管理者と担当リーダーのみ表示。リストと同じ見た目)
 ├─ リストの見出しをつかんでドラッグ → リストを並べ替え(すべてのリスト。管理者と担当リーダーのみ。ドラッグ中はリストが指に付いてくる。キーボードはリスト名を選んでスペースキー→矢印キー→スペースキー)
 ├─ 追加したリストの「…」→「名前を変更」「色を変更」「リストを削除」(タスクが入っていると削除できない)
 ├─ カードにはタイトル/タグ/期限/コメントの有無(アイコンのみ。件数は出さない)/担当者(アイコンを3人まで。それ以上は「+N」)を表示
 ├─ タグはタイトルの右端に2つまで(それ以上は「+N」。「緊急」は必ず先頭)
 ├─ タイトルは1行で表示し、入りきらないときは右から左へ流れ続ける(1秒あたり約25px。動きを減らす設定のときは流さず末尾を「…」)
 ├─ リストの幅は320pxで固定(タスク名の長さや画面幅で変わらない。入りきらないときはボードが横スクロール)
 ├─ 期限は今日からの日数で色を付ける:7日以内(期限切れを含む)は赤、8〜14日は黄色、15日以上は緑。完了・対応中止は色なし
 ├─ カードを別の列にドラッグ&ドロップ → ステータスを変更(追加したリストへの移動も同じ)
 ├─ 未対応・対応中の列の「＋」→ 作成モーダル(押した列のステータスが初期値)
 ├─ カードをクリック → タスク詳細
 └─「←」→ プロジェクト一覧

タスクの作成・編集(モーダル)
 ├─ タイトル
 ├─ ステータス・期限/画面名・タグ(2行2列。タグは複数選択で、候補にはタグの意味も表示)
 ├─ その下に担当者(複数選択。1人以上。新規作成では自分がメンバーなら自分が初期値)
 └─ 説明/修正内容・修正理由/Git URL/メモ
      └─ 修正内容の下に画像(原因となる画面のスクリーンショットなど。10枚まで)。
         修正内容に Ctrl + V で貼り付け・ドラッグ&ドロップ・「画像を追加」で追加。サムネイルの「×」で外す、押すと大きく表示。
         保存したときにタスクに付く(キャンセルしたら付かない)。送っている途中は保存できない。コピーでは引き継がない
※編集中にほかの人が先にそのタスクを更新していたら、保存せずに上部へ警告を表示する(「最新の内容を開く」で最新の詳細を開き、編集し直す)

画面名の管理(モーダル)
 ├─ プロジェクトに登録された画面名を名前順で表示(使っているタスク数付き)
 ├─ 画面名を入力して「追加」
 ├─「編集」アイコン → その場で名前を変更して「保存」
 └─「削除」アイコン → 削除(タスクで使われている画面名は削除できない)
※タスクの作成・編集では、画面名をここで登録したものからプルダウンで選ぶ(必須)。新しい画面の場合は先にここで登録する

タスク詳細(モーダル)
 ├─ タイトルの横に「リンクをコピー」アイコン(/tasks/{ID} の URL をコピー)。タスクの ID(#12)は表示しない
 ├─ タイトルの下に、期限・画面名/担当者・タグを2行2列で表示
 ├─ 上の帯の左にステータス、右に「⋮」「✖︎」。その下を、左の詳細と右のコメント欄(薄いグレーの背景)に分ける
 ├─ 詳細はそれだけでスクロールする。未入力の項目は「—」と表示する
 ├─ 右にコメント欄(見出しは「コメント」のみで件数は出さない。古い順。人のコメントはアイコン・名前・経過時間・本文、作成・移動・変更の自動コメント(変更履歴)はアイコン付きの小さいグレーの文字)
 │    ├─ 本文の「#ID」はそのタスク、URL はそのページへのリンク(別タブで開く)。このシステムのタスクの URL と「#ID」はタスク名で表示する(見られないタスクは書かれたまま)
 │    ├─ 本文の「@ユーザー名」(メンション)は色を付けて表示する(自分へのメンションはオレンジ)
 │    ├─ 入力欄と「送信」は横一列で、コメント欄の一番下に固定(コメントの一覧だけがスクロールする。Ctrl + Enter でも送信)
 │    │    └─「@」を打つと、入力欄の上にメンションの候補(プロジェクトのメンバーと管理者。自分は除く)を出す。
 │    │       続けて打った文字で絞り込み、↑↓で選んで Enter / Tab(またはクリック)で「@ユーザー名 」を入れる。Esc で候補だけ閉じる
 │    └─ 自分のコメント(管理者は全員のコメント)は削除できる。自動コメントは削除できない
 ├─ 上の帯の右端に「⋮」(その他の操作)と「✖︎」(閉じる)。下に「閉じる」などのボタンは置かない
 ├─ 担当者に含まれる一般ユーザーには「⋮」の左に「中止依頼」ボタン(担当していないタスク、完了・対応中止のタスクには出さない)→ 確認モーダル(理由は任意)→「依頼する」で管理者・担当リーダーに通知。送ったあとは「中止依頼済み」
 ├─ ステータス/タイトル/期限/画面名/担当者(全員)/タグ(マウスを合わせると意味を表示)/説明/修正内容(貼った画像のサムネイル付き。押すと大きく表示し、← → で切り替え・別タブで開ける)/修正理由/Git URL/メモを表示
 └─「⋮」を押すと、上から「編集」「コピー」「削除」のメニュー
      ├─「編集」→ 編集モーダル(編集できないタスクでは押せない)
      ├─「コピー」→ 作成モーダル(内容をコピー。Git URL・期限・修正内容・修正理由・メモは空)
      └─「削除」→ 削除確認モーダル(管理者・リーダーのみ表示)

ユーザー一覧
 ├─ ユーザーを縦一列のカードで表示(id順。アイコン/名前/権限/参画プロジェクト数。idは表示しない)
 ├─ 管理者には、ロックされているユーザーに「ロック中」を表示する
 ├─「＋」→ 登録モーダル(アイコン画像/ユーザー名/パスワード/権限)
 ├─「編集」アイコン → 編集モーダル(パスワードは変更する場合のみ入力)
 │    ├─ アイコン画像:「画像を選ぶ」で選ぶと、中央で正方形に切り抜いた見た目を表示する(保存で反映)。「画像を外す」で頭文字に戻す
 │    └─ ロックされているユーザーを管理者が編集するときは、上に「ロックされています」と「ロックを解除」を表示する
 ├─「削除」アイコン → 削除確認モーダル
 └─ カードをクリック → ユーザー詳細

ユーザー詳細(モーダル)
 ├─ 右上に編集アイコン(管理者か本人のときのみ。主の色)と「✖︎」(閉じる)。下にボタンは置かない
 ├─ 名前/権限/参画しているプロジェクト名(期限が近い順。見出しに件数は出さない)を表示
 ├─ プロジェクト名をクリック → タスク一覧(管理者か本人が見ているときのみ)
 └─ 編集アイコン → 編集モーダル

アクセス詳細
管理者
・ログイン画面
・プロジェクト一覧→作成・編集・削除が可能(プロジェクト名や詳細、メンバーなど)
・タスク一覧→全プロジェクトのタスク一覧に移動できる。全てのステータスに移動できる
・タスク詳細→編集・コピー・削除が可能
・ユーザー一覧→登録・編集・削除が可能(自分自身の削除と、自分の権限の変更はできない)

リーダー
・ログイン画面
・プロジェクト一覧→担当しているプロジェクトは編集が可能(名前・詳細・期限・メンバー・フェーズ)。それ以外は閲覧のみ(詳細モーダル)。作成・削除は不可。メンバーになっているプロジェクトのみタスク一覧に移動できる
・タスク一覧→作成が可能。全てのステータスに移動できる
・タスク詳細→編集・コピー・削除が可能
・ユーザー一覧→全ユーザーを閲覧できる。自分のアカウント(名前・パスワード)のみ変更可能

一般ユーザ
・ログイン画面
・プロジェクト一覧→閲覧のみ(詳細モーダルでプロジェクト詳細・メンバーを確認できる)。メンバーになっているプロジェクトのみタスク一覧に移動できる
・タスク一覧→作成が可能。自分が担当するタスクのみ未対応/対応中/レビュー中に移動できる
・タスク詳細→自分が担当するタスクのみ編集が可能(ステータス(未対応/対応中/レビュー中まで)/修正内容/修正理由/git url/メモ)。コピーが可能。削除は不可
・ユーザー一覧→全ユーザーを閲覧できる。自分のアカウント(名前・パスワード)のみ変更可能
