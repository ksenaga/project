# タスク管理システム

## 概要

チーム内のタスクを登録・管理し、プロジェクトやタスクの進捗を把握するためのタスク管理システムです。

タスクの対応内容・修正理由・Git URL・メモなどを記録し、後から修正内容や対応方法を確認できるようにします。

## 目的

本システムは、チーム内のタスク管理を行うことを目的としています。

また、React・Node.js・Express・MySQLを使用し、フロントエンドからバックエンド、データベースまで一通り実装することで、Webシステム全体の仕組みを理解することを目的とします。

## 主な機能

### 認証

* ログイン

### ユーザー管理

* ユーザー一覧
* ユーザー登録
* ユーザー編集
* ユーザー削除
* 自分のアカウント編集

### プロジェクト管理

* プロジェクト一覧
* プロジェクト作成
* プロジェクト詳細
* プロジェクト編集
* プロジェクト削除
* プロジェクトメンバー管理

### タスク管理

* タスク一覧
* タスク登録
* タスク詳細
* タスク編集
* タスク削除
* 担当者設定
* ステータス管理
* 修正内容・修正理由・Git URL・メモの記録

## 利用者

* 管理者
* リーダー
* 一般ユーザー

## 技術構成

* Frontend: React / TypeScript / MUI
* Backend: Node.js / Express / TypeScript
* Database: MySQL
* Authentication: JWT (Cookieに保存)

## システム構成

```text
Browser
   │
   │ HTTP
   ▼
React
   │
   │ API
   ▼
Node.js / Express
   │
   │ SQL
   ▼
MySQL
```

## データ構成

主なテーブル：

* users
* projects
* project_member
* tasks

## ステータス

タスクのステータス：

* 未対応
* 対応中
* レビュー中
* 完了
* 対応中止

## 対象外

現時点では以下を対象外とします。

* スマートフォン対応
* メール通知
* Slack通知
* ファイルアップロード
* 複数企業対応
* 高度な検索
* CSV出力

## 開発環境

### 必要なもの

* Node.js

* MySQL

### セットアップ

後述予定。

## 開発方針

本システムでは、既存のフレームワークに依存して実装するのではなく、フロントエンド・バックエンド・データベースの責務や処理の流れを理解しながら開発する。

要件定義 → 画面設計 → DB設計 → API設計 → 実装の順に進める。
